# ciencia-dados-python-faculdade
Este repositório contém o trabalho prático de Ciência de Dados focado na análise de um conjunto de dados de clientes de cartão de crédito. O objetivo principal é explorar o comportamento de faturas e pagamentos através de técnicas de estatística descritiva e visualização de dados com Python.
# Aplicação Prática de Python na Ciência de Dados - Parte 2

## Descrição do Projeto
Este projeto consiste na análise das características financeiras de um conjunto de dados de clientes de cartão de crédito. O objetivo é explorar faturas (`BILL_AMT`) e pagamentos (`PAY_AMT`), utilizando técnicas estatísticas e visualizações gráficas.

## Exercícios Realizados
1.  **Estruturação de Dados**: Criação de listas para organizar as características financeiras.
2.  **Análise Estatística**: Uso do método `.describe()` para examinar as sínteses das faturas.
3.  **Visualização**: Plotagem de histogramas em grade 2x3 para faturas e pagamentos.
4.  **Tratamento de Dados**: Uso de máscaras booleanas para identificar pagamentos iguais a zero.
5.  **Transformação Logarítmica**: Aplicação de `np.log10` para normalizar a escala dos gráficos de pagamento.

## Tecnologias Utilizadas
*   Python 3
*   Pandas (Manipulação de dados)
*   NumPy (Cálculos matemáticos)
*   Matplotlib (Geração de gráficos)
